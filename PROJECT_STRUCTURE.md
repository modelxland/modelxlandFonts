# Modelx Land Website Editing Guide

This file is the map for the whole website. Use it when you want to know exactly where to edit any text, image, button, layout, color, mobile style, desktop style, or JavaScript behavior.

## Very Important Rules

1. The live pages are:
   - `index.html`
   - `model-classic.html`

2. The `sections/` folder is for organized editing snippets only. It does not automatically build the live pages.

3. If you edit a file inside `sections/`, copy the same change into the matching live page:
   - Home snippets go into `index.html`.
   - Product snippets go into `model-classic.html`.

4. The checkout modal is generated by JavaScript at runtime.
   - To edit the actual modal content, edit `js/script.js`.
   - To edit modal desktop design, edit `css/desktop/checkout-modal.css`.
   - To edit modal mobile design, edit `css/mobile/checkout-modal.css`.
   - The modal HTML inside `index.html`, `model-classic.html`, and `sections/*/order-modal.html` is mostly a placeholder.

5. Desktop and mobile styles are separate:
   - Desktop/PC styles live in `css/desktop/`.
   - Phone styles live in `css/mobile/`.
   - Shared styles live in `css/shared/`.

The checkout modal appears on both pages, but the real modal content is generated by `js/script.js`.

Edit:

- `js/script.js`

Look for:

- `modal.innerHTML =`
- `order-summary-panel`
- `payment-options-list`
- `step1`
- `step2`
- `step3`
- `step4`

Modal steps:

1. `step1` payment method choice.
2. `step2` delivery/customer information.
3. `step3` payment reference.

- `selectPaymentMethod(method)` chooses payment type.
- `updatePaymentDetails()` updates payment labels/logos.
- `nextStep()` validates customer info and moves to payment.
- `prevStep()` returns to customer info.
- `submitOrder()` validates payment reference and shows success.
- `copyNumber()` copies payment number.
- `normalizeOrderPrice(price)` normalizes product price.
- `formatOrderPrice(price)` formats price display.

## Recommended Edit Workflow

1. Find the website part in the Fast Editing Index.
2. Edit the live page first: `index.html` or `model-classic.html`.
3. If a matching snippet exists in `sections/`, update that snippet too so the organized copy stays fresh.
4. Edit desktop CSS in `css/desktop/`.
5. Edit phone CSS in `css/mobile/`.
6. Edit shared CSS only when the change should affect multiple pages.
7. If behavior changes, edit the correct JS file.
8. Check the page in browser on desktop and mobile width.
