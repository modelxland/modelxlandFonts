# Section Snippets

These files split the big HTML pages into smaller chunks for easier editing and reading.

- `desktop/home/` mirrors the main sections from `index.html`.
- `desktop/product/` mirrors the main sections from `model-classic.html`.
- `mobile/` keeps mobile-only snippets that are embedded in the live pages.

The live pages are still `index.html` and `model-classic.html`. Update the matching live page section when you change a snippet. These snippets are not automatically loaded by the browser yet.

Use `../PROJECT_STRUCTURE.md` as the main editing map. It explains exactly which file controls each section, class, style, image, and script.
